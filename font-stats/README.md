# 字体使用统计（font-stats）v1.1.1

一键统计一个字族的**字面数量**和**版权分类**，结果写进该字族的备注，在软件里直接可见。

| | |
|---|---|
| 分类 | 📊 数据统计 |
| 权限 | `read:fonts` · `write:curation` |
| 运行环境 | **自带** Python 3.13（`runtime/`，无需安装任何东西） |

## 使用

1. 在任意字族上**右键 → 插件 › 字体使用统计 › 统计这个字族**
2. 插件查询该字族的所有字面，按版权判定结果分组计数
3. 把结果写进该字族的**备注**（覆盖原有备注，注意先备份重要备注），例如：

   > 【统计】4 个字面；版权分类：免费商用 3 个、未知 1 个

4. 完成后弹 toast；打开该字族的详情/备注即可看到

## 版权分类说明

分类来自 FontManager 内置的版权判定引擎（按授权文件关键词、目录名等证据链），
常见结果：**个人免费 / 收费 / 免费商用 / 未知**。「未知」通常意味着目录里
没有可识别的授权文件——不代表不能商用，请自行核实原厂授权。

## 卸载

**设置 → 插件** 关掉开关，删掉插件目录即可。已写入的备注留在字族上，
不想要就手动清掉。
