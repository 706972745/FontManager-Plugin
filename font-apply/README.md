# 字体套用（PS / AI / CDR）· font-apply 1.0.0

右键一个字族 → 直接套用到 Photoshop / Illustrator / CorelDRAW 当前选中的文字上。

它是个**薄插件**：套用这件事由主程序执行（`POST /api/v1/fonts/apply`），
本插件只负责挑字重、认目标、把结果翻成一句人话。所以这里**一行 COM / JSX / PowerShell 都没有**，
也不会出现「主程序修好的问题插件里还在」。

## 四条菜单

在字体库（卡片 / 列表 / 速览都行）里右键一个字族：

| 菜单项 | 行为 |
|---|---|
| 应用到 Photoshop | 套到 Photoshop 当前选中的文字上；没选文字就新建一个文本框 |
| 应用到 Illustrator | 同上 |
| 应用到 CorelDRAW | 同上（走主程序的常驻 COM 宿主，首次会慢 3~4 秒） |
| 自动：应用到最近使用的设计软件 | 由主程序判断你最近在用的是哪个，再套过去 |

用哪一个字面：**Regular 优先**，没有 Regular 就取第一个有 PostScript 名的字面。
选中的是哪个字重，提示里会写出来（「思源黑体 Bold」）。

## 「自动」怎么认目标

调 `GET /api/v1/apps/active`，规则是主程序定的：

1. 先看**前台窗口**；
2. 前台是 FontManager 自己、或者是任务栏 / 桌面（`explorer.exe`）时，沿窗口 Z 序往下翻
   （最多 30 个），跳过不可见 / 最小化 / 带 owner 的窗口，第一个属于 PS / AI / CDR 的就是答案；
3. 前台是别的软件时直接算「没有」—— 那种情况下你确实不在用设计软件。

所以**点任务栏上的 PS 图标切过去也认**：那一刻前台先变成任务栏，往下翻就能翻到 PS。
一个都没开时提示「没找到正在运行的设计软件（PS / AI / CDR）」。

## 双击也能套用（主程序 1.9.12+，1.9.13 起只在速览界面）

主程序 1.9.13 起，**速览界面里所有「点击复制」的位置双击就是套用**：整行、展开的字重行。
双击时主程序会把这次手势**转发给本插件的「自动」项**，所以双击和右键点「自动」走的是
同一条路径。双击转发会带上 `payload.faceId`：**双击哪一行字重就套哪个字重**。

完整界面（卡片 / 样张 / 详情面板）**不响应双击** —— 那里双击是「选中 / 展开」的地盘，
再叠一个隐式动作会互相打架。要套用请用右键菜单。

### 两种双击行为（设置 → 插件 → 齿轮，或插件右键菜单「双击行为…」）

| 设置 | 双击之后 |
|---|---|
| **直接套用到最近在用的设计软件**（`auto`，默认） | 主程序告诉我们最近在用的是 PS / AI / CDR 中的哪一个，直接套过去 |
| **先选窗口**（`pick`） | 先弹一句「点一下要应用到的窗口（15 秒内）」，然后**点一下**目标窗口 |

存在插件目录下的 `config.json`：`{"doubleClickMode": "auto"}`。缺文件 / 内容坏 /
写了别的值，一律按 `auto`。

`pick` 模式的细节：
- 选窗口时**面板上会出现一条常驻提示**「点一下要应用到的窗口 · 15 秒内」
  （主程序 1.9.14+ 的 `hint` 通道，渲染在速览元信息行；老版本只发 toast）；
- 15 秒内没点任何别的窗口 → 提示「已取消：15 秒内没有选择窗口」；
- 点到别的软件 → 提示「这不是 PS / AI / CDR 窗口，没有套用」；
- **点任务栏切过去也认**：那一刻前台先变成 `explorer.exe`，有 1.5 秒宽限等系统激活真正的窗口；
- 宽限到期还是任务栏 → 按「非目标」处理，不用干等 15 秒；
- **离开过又点回 FontManager** → 视为取消，立刻提示「已取消」，不用等满 15 秒。

### 为什么 pick 由插件自己做

用户的口径是「主程序尽量只开放端口，其他尽量由插件解决」。所以主程序里**没有**任何
窗口轮询逻辑，它只把双击转成一次插件调用；等窗口这件事完全在插件进程内用 `ctypes`
调 `GetForegroundWindow` + Toolhelp32 完成（见 `pick.py`）。

代价是插件里多了几十行 Win32 调用，换来的是：主程序不装全局钩子、不认识任何具体插件，
换一个实现了同样菜单的插件也能用。

## 排障

| 现象 | 原因 / 怎么办 |
|---|---|
| 「{App} 里找不到「XX」——先在 FontManager 里启用它，再重启 {App}」 | 字体没启用，或启用后**没重启目标软件**。PS/AI/CDR 只在启动时读一遍系统字体表，装完必须重启一次 |
| 「{App} 没在运行」+「（可能以管理员身份运行…）」 | 目标软件是提权启动的，普通权限的 COM 打不进去。要么用同样权限启动 FontManager，要么别用管理员身份开 PS/AI/CDR |
| 「{App} 没响应（可能弹着对话框 / 正在渲染）」 | 目标软件正在弹模态对话框（另存为、缺字体提示…）或者正忙着渲染。关掉对话框再点一次 |
| 「{App} 没打开文档」 | 先新建 / 打开一个文档 |
| 「{App} 里选中的不是文字」 | 选中的是图层 / 形状 / 路径。用文字工具点一下文字，或者干脆不选（会新建文本框） |
| 「这个字族没有可用的字面」 | 这个族里的字面都没有 PostScript 名，套用无法定位 |
| 「没找到正在运行的设计软件」 | 三个软件一个都没开；或前台是别的软件且 Z 序里翻不到 |

其他情况看 `%APPDATA%\FontManager\activation.log`，本插件的输出都带
`[plugin:com.fontmanager.font-apply]` 前缀（`log` 是过程，`toast` 是弹给你的那句话）。

## 要求

- FontManager **1.9.11+**（`POST /fonts/apply` 与 `read:apps` 权限从这版开始有）
  - 设置面板开成应用内窗口要主程序 **1.4.3+**（更老的话降级用系统默认浏览器）；
  - 双击转发要主程序 **1.9.12+**，且 1.9.13 起只在速览界面生效。
- Python 3.10+（用系统里已装的，不自带运行时；只用标准库）
- Windows（CorelDRAW 本来也只有 Windows 版）
- 权限：`read:fonts`（挑字面）、`write:apply`（套用）、`read:apps`（自动认目标）
